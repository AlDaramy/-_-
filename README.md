# تطبيق متابعة حلقات القرآن الكريم — نسخة Windows (الإصدار 2)

## أول مرة
1. ارفع محتويات هذا المجلد (ومعها `.github`) على مستودعك.
2. تأكد أن **Settings ← Actions ← General ← Workflow permissions** على **Read and write permissions**.
3. بعد نجاح **Actions** ✅ افتح قسم **Releases** في المستودع (يمين الصفحة).
   ستجد إصدارًا مثل `v2.0.5` وبداخله `Halaqa-Setup-2.0.5.exe` (مُثبِّت) و`Halaqa-Portable-2.0.5.exe`.
4. ثبّت `Halaqa-Setup` على جهازك مرة واحدة فقط.

## التحديثات بعد ذلك (تلقائية)
كل ما ترفع تعديلًا على المستودع يُبنى إصدار جديد برقم أعلى وينزل في **Releases**.
والتطبيق المثبّت على جهازك يفحص التحديثات عند فتحه (وكل 6 ساعات)، وينزّلها وحده،
ثم تظهر نافذة «إعادة التشغيل الآن / لاحقًا». لا تحتاج لتحميل شيء بنفسك.

- رقم الإصدار: الرقمان الأولان من `version` في `package.json` (الآن `2.0`) والثالث رقم البناء تلقائيًا.
  لإصدار كبير جديد غيّر `2.0.0` إلى `2.1.0` أو `3.0.0`.
- النسخة المحمولة (Portable) لا تتحدث تلقائيًا؛ استخدم المُثبِّت.
- يظهر رقم الإصدار أسفل صفحة **الإعدادات** في التطبيق.
- قد يظهر تحذير SmartScreen أول مرة: **More info** ثم **Run anyway**.
