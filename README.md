# تطبيق متابعة حلقات القرآن الكريم — نسخة Windows

1. أنشئ مستودعًا جديدًا على GitHub وارفع **كل محتويات هذا المجلد** (ومعها المجلد المخفي `.github`) على الفرع `main`.
2. افتح تبويب **Actions** ← انتظر نجاح **Build Windows app** ✅ (نحو دقيقتين).
3. افتح التشغيل الناجح، وانزل إلى **Artifacts**، وحمّل `Halaqa-Windows` ثم فك الضغط.
4. شغّل `Halaqa-Setup-1.0.0.exe` (مُثبِّت) أو `Halaqa-Portable-1.0.0.exe` (بدون تثبيت).
   لو ظهر تحذير SmartScreen: **More info** ثم **Run anyway**.

البيانات تُحفظ على الجهاز نفسه؛ خذ نسخة احتياطية من **الإعدادات ← تصدير البيانات** من وقت لآخر.
